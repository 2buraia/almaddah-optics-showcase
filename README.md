## About The Project

**ALMADDAH Optics** is a production-grade digital storefront and enterprise store management system developed specifically for the precision requirements of the optical and eyewear retail industry. 

While generic e-commerce platforms struggle with the compound complexities of prescription eyewear, ALMADDAH Optics integrates a customized configuration workflow directly into the shopping journey. Customers can select their preferred designer frames, configure medical prescription parameters, choose certified international lens manufacturers, select specialized coatings, and order with real-time price updates and seamless Cash-on-Delivery fulfillment.

### Core Value & Problem Solved
- **Prescription Personalization**: Automates optical lens selection (Single Vision, Bifocal, Progressive) with multi-index thickness options (1.56, 1.60, 1.67) directly linked to frame compatibility.
- **Brand Synergy**: Built-in support for global lens pioneers (Essilor, ZEISS, Crizal, HOYA) with authentic branding and specifications.
- **Frictionless Purchasing**: Removes the intimidation of ordering medical eyewear online through an intuitive, visual step-by-step wizard.
- **Enterprise Operations**: A dedicated administrative management console enabling real-time inventory adjustments, lens pricing matrices, subcategory routing, and order tracking.

## Key Features

### Storefront Experience
- **Dynamic Category Filtering**: Fluid switching across Men, Women, Kids, Sunglasses, Optical Frames, and magnetic Clip-On eyewear.
- **Prescription Lenses Studio**:
  - Automatic activation for medical frames and clip-on styles.
  - Multi-brand catalog (Essilor, ZEISS, Crizal, HOYA).
  - Multi-tiered lens indices and type selectors.
  - Multi-coating protective options (Anti-Reflective Shield, Blue Cut, Hydrophobic Smudge-Repellent, Diamond Hard Coat, UV400).
  - Dynamic combined pricing calculation (Frame base + Custom lens additions).
- **Interactive Product Gallery**: Multi-angle photography viewer with interactive thumbnail switcher and color-synchronized variant previews.
- **Cash-on-Delivery Checkout**: Frictionless one-page order completion with client-side format validation and promotional coupon redemption.
- **Real-Time Announcement Marquee**: Dynamic top-bar ticker for seasonal promotions and service announcements.

### Management & Control Center
- **Executive KPI Dashboard**: Centralized performance metrics tracking catalog volume, category distributions, and incoming order volume.
- **Frame & Media Management**: Complete inventory control with multi-color swatches, hover photography assignments, and specification highlights.
- **Lenses Pricing Matrix**: Dedicated administrative interface to manage lens brand portfolios, specifications, and coating add-on fee structures.
- **Order Tracking & Fulfillment**: Detailed order summaries including full customer contact info, delivery instructions, and complete lens customization specifications.
- **Promotions Engine**: Flexible discount coupon creator supporting percentage-based and fixed-value reductions with spend minimums.

## Technology Stack

| Domain | Technology / Specification | Purpose |
| :--- | :--- | :--- |
| **Frontend Architecture** | Modern Vanilla JavaScript (ES6+) | Lightweight, reactive client-side state & UI rendering with zero framework overhead |
| **Styling & Design System** | Native CSS3 with Custom Tokens | Luxury typography, custom gold & dark palettes, responsive fluid grid, CSS transitions |
| **Typography & Assets** | Google Fonts (Playfair Display, Inter) & Font Awesome 6.5.2 | High-legibility luxury typography and universal interface iconography |
| **Backend REST API** | PHP 8.x (Stateless JSON Endpoints) | Fast, modular endpoints for catalog delivery, order capture, and admin operations |
| **Database Layer** | MySQL / MariaDB (InnoDB, `utf8mb4`) | Relational persistence with foreign keys, transactional integrity, and automated schema migration |
| **Deployment & Hosting** | Apache / LiteSpeed on Hostinger Cloud | Production environment with HTTP caching, gzip compression, and SSL encryption |

---

## Architecture & Engineering Highlights

- **Zero-Bloat Performance**: Built using native web standards without heavy third-party framework dependencies, ensuring instantaneous page loads and low network overhead.
- **Self-Healing Schema Migrations**: The backend incorporates an automated database integrity engine that validates and provisions required tables, indexes, and seeded records upon environment deployment.
- **Security-First Data Handling**: PDO prepared statements with strict parameter binding throughout the API layer mitigate SQL injection vulnerabilities, complemented by comprehensive input sanitization.
